# Codex GPT-6 Luna pilot notes

Research only; no model inference or trial tasks were run.

- Local CLI is `codex-cli 0.160.0`; `codex login status` reports **Logged in using ChatGPT**. `codex debug models` lists exact slug `gpt-6-luna` (display name `GPT-6-Luna`). This confirms the CLI knows the model name, not account entitlement; the model catalog is local CLI metadata. The collaboration model list does not establish CLI access either. A real request is required to confirm account access.
- Local `codex exec --help` confirms noninteractive usage and flags `--model`, `--json`, `--ephemeral`, `--ignore-user-config`, `--output-last-message`, and `--output-schema`. `--json` emits JSONL events. For paired task usage capture, record the `turn.completed` event’s `usage.input_tokens` and `usage.output_tokens`; `item.started` / `item.completed` include command execution items. OpenAI's eval guide documents JSONL parsing and usage fields: [Testing Agent Skills Systematically with Evals](https://developers.openai.com/blog/eval-skills).
- Suggested invocation shape, once the pilot is authorized: `codex exec --model gpt-6-luna --json --ephemeral --ignore-user-config -C <worktree> <prompt>`. Use the same CLI auth that `codex login status` reports, and ensure `OPENAI_API_KEY` is absent from the process environment so the request cannot switch to API-key billing. Keep paired baseline/treatment worktrees and prompts identical; `--ephemeral` avoids saving rollout session files. `--ignore-user-config` avoids model/provider overrides from `config.toml` but does not itself force ChatGPT auth.
- ChatGPT sign-in uses ChatGPT plan usage/billing; an API key uses API pricing. ChatGPT and API billing are separate products ([billing guide](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform), [Codex plan guide](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)). API billing can be excluded by using ChatGPT auth and not supplying an API key.
- **Paid-usage caveat:** ChatGPT plan usage may draw on shared usage credits after included limits. Credits are pay-as-you-go; auto-reload can be enabled, and its monthly maximum only constrains auto-reload, not one-time credit purchases ([credits guide](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)). Disable auto-reload and do not purchase credits for a strict subscription-only pilot. Codex CLI exposes no per-run or total-spend cap in its local help. Thus there is no CLI-enforced hard dollar ceiling; subscription allowances/limits bound included usage, while any extra credit spending is controlled in the account UI. Confirm the account's credit balance and auto-reload state before trials if zero extra spend is required.

Sources checked: local `codex --help`, `codex exec --help`, `codex debug models`, `codex login status`; official OpenAI pages linked above. No credentials or secrets were read or recorded.
